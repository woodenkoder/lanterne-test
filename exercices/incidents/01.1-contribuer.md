# 🔥 Incident · Main a disparu… encore

> **De :** Sam, développeur
> **À :** l'équipe de la Lanterne
> **Salle :** La Crypte des branches · combat 01.1

Hier, quelqu'un a poussé directement sur main, en force. Trois commits de l'équipe ont disparu, et personne ne sait qui a fait quoi : les messages disent tous « update ». À partir d'aujourd'hui, tout passe par une pull request.

```text
$ git log --oneline -3 main
9f2c1e1 update
77a03b4 update
c1d9e0f wip
```

**Le monstre :** Le Fantôme du merge. Il fait disparaître du code, et personne ne sait comment.

**Ta mission :** faire passer une modification par le chemin complet : branche, commits propres, pull request, fusion.
La consigne complète est dans le manoir (combat 01.1, « Ta première pull request dans les règles »).

**Lancer le combat :** Une fois ta pull request fusionnée : onglet **Actions** → **Manoir** → **Run workflow**, champ exercice : `contribuer`. Le résumé du run te dit combien de points de vie il reste au monstre.
